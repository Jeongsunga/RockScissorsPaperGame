### **유저 스토리**
1. 유저는 박스 두 개를 볼 수 있다. (타이틀, 사진, 결과)  
2. 유저는 박스 하단에 가위바위보 버튼을 볼 수 있다.  
3. 버튼을 클릭하면 클릭한 아이템이 유저 박스에 보인다.  
4. 버튼을 클릭하면 컴퓨터 아이템은 랜덤하게 선택된다.  
5. 3번 4번 아이템을 가지고 누가 이겼는지 승패를 나눈다.  
6. 박스 테두리가 결과에 따라 색이 변한다.  
   지면 빨간색, 이기면 초록색, 비기면 검정색이 보인다.
